## How I work

- **Diagnose before building.** I audited 100+ sales chats before automating any of them.
- **Rules first, AI second.** Deterministic code for what's predictable; a model only for what isn't.
- **Never trust the model.** AI output passes the same validation as typed input, and is labelled.
- **Say what it can't do.** Every case study has a Limits section.
